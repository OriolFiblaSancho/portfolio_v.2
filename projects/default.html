Manual de uso / Instrucciones

Sigue estos pasos para desplegar o interactuar con la aplicación:

  1. Clona el repositorio desde GitHub de forma local.
  2. Instala las dependencias ejecutando npm install en tu terminal.
  3. Configura las variables de entorno en el archivo .env.
  4. Inicia el servidor de desarrollo con npm start.
