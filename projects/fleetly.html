Control de flotas

Fleetly

VUE TypeScript Laravel PostgreSQL Docker

Introducción y Propósito

Fleetly es una solución integral B2B para la gestión de flotas vehiculares, diseñada para optimizar la operación y reducir costos en empresas que manejan múltiples vehículos. El proyecto busca proporcionar una plataforma intuitiva y eficiente para el seguimiento, mantenimiento y análisis de la flota.

Arquitectura y Desafío Técnico

El núcleo de Fleetly es su arquitectura Multi-Tenant (SaaS) con aislamiento de datos en PostgreSQL. El sistema utiliza un esquema dinámico para la gestión de clientes (tenants), suscripciones y dominios, mientras que cada empresa opera de forma aislada en su propio esquema independiente (tenant_x).

El backend está construido sobre Laravel siguiendo un patrón MVC ( Model-View-Controller), localizando las migraciones y la lógica de negocio dentro de cada dominio (Vehículos, Reservas, Incidencias) para garantizar un sistema escalable y mantenible.

Mi Contribución Especializada

Como encargado del desarrollo de los roles de SuperAdmin (Global Admin) y Admin de Tenant, implementé módulos críticos para la administracion de la plataforma:

  • Panel Global (SuperAdmin): Creación del backend y frontend para la gestión de empresas (CRUD de Tenants), asignación de planes de suscripción, control de subdominios dinámicos y analíticas globales de la plataforma.
  • Control de Acceso y Permisos (RBAC): Integración de políticas de seguridad avanzadas y control de roles mediante herramientas robustas (Spatie), asegurando que el personal operativo (Workers) y los administradores gestionen recursos sin solapar privilegios.
  • Pasarela de Pagos y Facturación: Colaboración en el flujo de facturación automatizada y estructuración de tablas complejas para el procesamiento seguro de pagos mediante Stripe.

Características de Ingeniería Destacadas

  • Aislamiento de Datos Dinámico: Enrutamiento automático de conexiones de bases de datos basado en el subdominio del cliente (ej. acme.fleetly.com).
  • Geofencing Avanzado: Implementación de perímetros y zonas restringidas nativas en base de datos mediante polígonos de PostgreSQL.
  • Modularidad en Frontend: SPA estructurada en Vue 3 y TypeScript orientada a dominios independientes, garantizando un código limpio y desacoplado.

Conclusión

Fue el proyecto de fin de grado que me toco desarrollar, cuenta con diversas caracteristicas muy utiles para una empresa necessitada de una aplicacion de control de flotas.

Entre las caracteristicas que se pueden encontrar en la aplicacion estan:

  • Control de vehículos, usuarios, reservas ...
  • Seguimiento en tiempo real
  • Reportes de incidencias
  • Gestión de mantenimiento
  • Alertas y notificaciones
  • Estadísticas y métricas
  • ChatBot por rol
